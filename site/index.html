KEEP YOUR WORKFLOW

A bridge, with
a light touch.

Your configuration, keymaps, plugins, and running jobs stay in Neovim. Neordr gives your other tools a way in.

01

The whole editor comes with you.

Edit files and run terminals in the same view. Select a terminal in the sidebar to focus it, ready for input. Create, rename, split, and reorder without leaving the client.

02

Your agents, in Chat View.

Run Claude or Codex inside a managed Neovim terminal. Moshi’s existing hooks find the agent and read its conversation. Send a message from Chat View and continue in the same job.

03

Leave the connection. Keep the work.

Discover running editor sessions and attach through Neovim’s remote UI. Detach a client while your editor and terminal jobs keep running.

SMALL PIECES, CLEAR OWNERSHIP

Neovim at the center.

Neordr speaks the Herdr interfaces that Moshi already uses. Neither Moshi nor moshi-hook needs a patch.

NeovimEditor · terminals · agents

One source of truth. Herdr’s complete contract types come from a pinned upstream source revision. Neordr implements the operations needed for its Neovim bridge.

Shared by design. Attached clients share editor focus and layout. Neovim renders at the smallest attached UI size; detach unused connections to release that constraint.

Bring your
own Neovim.

Neordr runs beside your editor. Install the CLI and Lua integration, then connect using the Herdr option in Moshi.

QUICK START01—03

  1. Install Neordr

    Download the archive for your host. It includes the executable and Neovim Lua integration.

    Installation instructions ↗

  2. Enable it in Neovim

    Add the bundled Lua integration to your runtimepath, then call:

    require('neordr').setup()

  3. Start a managed terminal

    Run :NeordrTerm, launch your agent, and select the session in Moshi’s Herdr picker.
